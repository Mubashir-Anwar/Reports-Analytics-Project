MONGODB DATA

Aggregation query

Mongo Shell style accepts single-quoted keys, NumberInt/NumberLong, and Jasper parameters such as $P{StartDate}. Both $P and $P! become typed URL values; raw text/code is never spliced into the query. JavaScript/Python are read as data-only pipeline literals; server-side code execution is disabled.

All styles convert to the same read-only MongoDB aggregation.
